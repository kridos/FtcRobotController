# FTC Robot Control Code (Freight Frenzy 2022 & Power Play 2023)

## Project Overview

This repository houses the control system code for our FIRST Tech Challenge (FTC) robots designed for the Freight Frenzy (2022) and Power Play (2023) seasons. The codebase utilizes Java and leverages the FTC SDK to implement functionalities crucial for competition success.

## Key Features & Functionalities

* **Autonomous Routines:** The code implements autonomous routines that enable the robot to perform pre-programmed actions without driver control, maximizing efficiency and point scoring.

* **Sensor Integration:** Sensor data from various sensors like distance sensors, color sensors, and inertial measurement units (IMUs) is integrated for real-time feedback and decision-making within the control system.

* **Precise Motor Control:** Precise motor control algorithms ensure the robot's movements are accurate and efficient, allowing for successful task completion.

* **Teleoperated Control:** The code facilitates intuitive teleoperated control of the robot during driver-controlled periods, allowing for skillful maneuvering and game strategy execution.

## Technologies Used

* **Java:** Primary programming language.

* **FTC SDK:** Official FIRST Tech Challenge Software Development Kit.

* **Robot Control Systems:** Core focus of the codebase.

* **Motor Control:** Specific algorithms and implementations for precise motor operation, including PID and Motion Profiling.

* **OpenCV:** Used for vision processing.

## Team Principles

This codebase reflects the collaborative effort of our FTC team and demonstrates our commitment to:

* **Optimizing for Limited Resources:** Considering the limitations of FTC robots in terms of processing power and battery life, the code is designed for efficiency and utilizes resources effectively.

* **Modular Design for Prototyping and Iteration:** The code is structured for modularity, enabling rapid prototyping, efficient troubleshooting, and iterative development throughout the FTC build season.

* **Clear and Concise Code Documentation:** Comments are incorporated within the code to enhance readability and understanding for future team members, facilitating efficient code maintenance and future development.
